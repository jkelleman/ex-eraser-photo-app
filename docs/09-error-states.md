# Error and empty states

Every error message says what happened, why it matters, and what the user can do next. Each one also gives a calm way out.

| Situation | Message | Buttons |
| --- | --- | --- |
| Limited photo access | "You've shared some of your photos with Ex-Eraser Photo App. To find every photo of [name], allow access to your full library." | Open Settings · Keep using selected photos |
| No face groups yet | "Your phone is still learning the faces in your library. This can take a while after a big import. Check back a little later." | Remind me later · Choose photos myself |
| The person isn't listed | "You can pick a few photos of them yourself, and I'll look for more like those." | Choose photos |
| No other matches found | "I couldn't find any other photos of [name]. If some are in an album or a Shared Library, you can add them yourself." | Add photos · Continue |
| Photo is in a Shared Library | "This photo is in a Shared Library, so changes would show up for everyone in it. I can make a private copy in your library and edit that instead." | Edit a copy · Skip this photo |
| Erase result looks wrong | "This one didn't come out right. You can try again, crop it, or keep it faded." | Try again · Crop instead · Keep faded |
| Low storage | "Your phone is almost out of space, so I've paused. Free up some room and we'll pick up where you left off." | Open Storage settings · OK |
| Returning after a pause | "Welcome back. You've finished 40 of 312 photos. Want to keep going?" | Keep going · Not today |
| Final delete review | "These 6 photos will move to Recently Deleted. They'll stay there for 30 days, then they're gone for good." | Delete 6 photos · Go back |
| Photo restored | "Restored. This photo is back to its original." | OK |
